# Αποθήκη Σκρατς — προδιαγραφή

Γραμμένη από την περιγραφή του Owner (4 Νοε 2026). **Δεν έχει χτιστεί τίποτα
ακόμα.** Τα ανοιχτά ερωτήματα στο τέλος πρέπει να απαντηθούν πρώτα — δύο από
αυτά αλλάζουν το σχήμα.

---

## 1. Τι είναι

Τα σκρατς που έχει το πρακτορείο **προς πώληση αλλά δεν είναι ακόμα στο
μαγαζί**. Νέα καρτέλα στο πλαϊνό μενού, κάτω από «Εθνικό Λαχείο».

Σήμερα το σύστημα ξέρει μόνο τι είναι στον πάγκο. Η αποθήκη είναι το
κομμάτι πριν από αυτό: τι παρελήφθη, τι περιμένει, πόσο αξίζει, και τι
κοντεύει να λήξει.

## 2. Ο κωδικός

Δεκατέσσερα ψηφία, τρία μέρη:

```
0157  3301482  014
└─┬─┘ └──┬──┘ └┬─┘
  │      │     └── αριθμός δελτίου μέσα στο πακέτο (000 έως N-1)
  │      └──────── μοναδικός κωδικός πακέτου (7 ψηφία)
  └─────────────── αριθμός παιχνιδιού (4 ψηφία, σταθερός ανά παιχνίδι)
```

**Καταχώρηση:** πρώτα ο 4ψήφιος — το σύστημα λέει αμέσως ποιο παιχνίδι
είναι — και μετά ο 7ψήφιος του πακέτου. Ο 3ψήφιος δεν καταχωρείται: είναι
το δελτίο μέσα στο πακέτο και το ξέρει το ταμείο.

## 4. Ροή ενός πακέτου

```
ΠΑΡΑΛΑΒΗ        4ψήφιος + 7ψήφιος + ημερομηνία
    ↓
ΑΠΟΘΗΚΗ         μετράει στην αξία αποθήκης· τρέχει το ρολόι λήξης
    ↓
ΜΑΓΑΖΙ          βγαίνει από την αποθήκη, μπαίνει στο ταμείο
    ↓
ΤΕΛΕΙΩΣΕ        όπως σήμερα, μέσω του ταμείου
```

ή, αντί για ΜΑΓΑΖΙ:

```
ΑΠΟΣΥΡΣΗ        βγαίνει από την αποθήκη χωρίς να πουληθεί
```

**Κρίσιμη αλλαγή στο ταμείο:** το «νέο πακέτο» δεν θα δέχεται πια
πληκτρολογημένο κωδικό. Θα **διαλέγει** από τα πακέτα που υπάρχουν στην
αποθήκη για το συγκεκριμένο παιχνίδι. Το πακέτο μεταφέρεται — φεύγει από
την αποθήκη τη στιγμή που μπαίνει στον πάγκο.

Αυτό κλείνει το κενό που περιγράφει ήδη ο κώδικας: *«a mistyped code
recorded today is a pack nobody can trace tomorrow»*.

## 5. Αξία αποθήκης

Σύνολο σε ευρώ, και ανά παιχνίδι. Αξία πακέτου = **δελτία × τιμή** — όχι
σταθερά 300 €, γιατί το 7ΑΡΙ Χ50 είναι 750 €.

## 6. Ειδοποιήσεις λήξης

Το ρολόι ξεκινά από την **ημερομηνία παραλαβής**.

| Ημέρες στην αποθήκη | Τι γίνεται |
|---|---|
| 0 – 84 | τίποτα |
| **85 – 89** | ειδοποίηση: πλησιάζει η λήξη |
| **90 – 110** | έντονη ειδοποίηση |
| 110+ | μένει κόκκινο μέχρι να αποσυρθεί |

## 7. Οθόνη

- Λίστα πακέτων με: παιχνίδι, κωδικό, ημερομηνία παραλαβής, ημέρες στην
  αποθήκη, αξία
- **Ταξινόμηση** ανά κωδικό και ανά ημερομηνία, ώστε να φαίνονται τα παλιά
- **Απόσυρση** πακέτου
- Σύνολο αξίας, πάνω
